# TogoAPI 隐私政策

**生效日期：2026 年 8 月 1 日**

TogoAPI 由个人运营者提供和维护。本政策说明我们在提供网站、账户、API、计费和客户支持服务时如何处理个人信息。

## 一、我们处理的信息

根据您使用的功能，我们可能处理：

1. **账户信息**：用户名、邮箱地址、加密后的密码凭证、账户状态和身份验证记录；
2. **接口与用量信息**：API Key 标识、调用时间、模型、令牌用量、费用、响应状态和必要的故障元数据；
3. **设备与安全信息**：IP 地址、User-Agent、登录时间、安全事件和风险控制记录；
4. **交易信息**：订单号、充值金额、支付状态和退款处理记录。完整支付凭证由相应支付服务提供商按照其政策处理；
5. **客服信息**：您通过微信主动提供的账号、订单号、问题描述及其他为处理请求所需的信息；
6. **本地浏览器信息**：登录令牌、界面偏好及协议同意版本等必要数据可能保存在浏览器本地存储中。

## 二、请求内容处理

为完成您发起的模型请求，TogoAPI 会将提示词、上传文件及相关请求内容传输至对应的上游服务提供商，并将模型回复返回给您。

TogoAPI 不将提示词、上传文件或模型回复正文作为常规业务数据持久保存，也不使用这些正文进行广告画像或出售。请求内容在传输和处理过程中可能短暂存在于服务器内存、网络缓冲区及必要的安全处理链路中，完成请求后不作为常规记录保留。

上游服务提供商将按照其自身条款和隐私政策独立处理请求内容。您不应提交无权处理的个人信息、商业秘密、受保护数据或其他敏感内容。

## 三、处理目的

我们仅在提供服务所必需或法律允许的范围内处理信息，包括：

- 创建和维护账户、验证身份及保障账户安全；
- 转发 API 请求、计算用量、扣减余额并展示账单；
- 防止欺诈、攻击、密钥滥用和其他违规行为；
- 处理充值、退款、故障排查和客户支持；
- 履行法律义务、响应依法提出的请求及解决争议；
- 改进服务稳定性、性能和用户体验。

## 四、共享与委托处理

我们不会出售您的个人信息。为提供服务，必要信息可能被提供给：

1. 您选择调用的人工智能模型及基础设施服务提供商；
2. 支付、邮件、网络加速、安全防护和云服务提供商；
3. 根据法律法规、司法或行政机关依法提出的要求，有权获取信息的主体；
4. 为保护用户、平台或第三方合法权益确有必要的专业顾问或技术服务方。

我们会尽合理努力仅提供实现相应目的所需的信息，并要求服务提供方采取适当保护措施。

## 五、跨境处理

部分上游模型或基础设施可能位于您所在国家或地区之外。使用相关服务可能涉及必要的数据跨境传输。我们仅在适用法律和上游服务规则允许的地区提供服务；您应避免在请求中提交不适合跨境处理或缺乏合法依据的数据。

## 六、保存期限

我们在实现本政策所述目的所需的期限内保存账户、用量、交易、安全和客服记录，并根据法律义务、争议处理、反欺诈和系统安全需要确定具体期限。保存目的消失且法律没有另行要求后，我们将删除或匿名化相关信息。

提示词、上传文件和模型回复正文不作为常规业务记录持久保存；上游服务提供商的保存期限由其自身政策决定。

## 七、安全措施

我们采取访问控制、凭证加密、传输加密、权限隔离、日志审计和风险监测等合理措施保护信息。但互联网传输和信息系统无法保证绝对安全，您应妥善保管密码与 API Key，并避免提交不必要的敏感信息。

## 八、您的权利

在适用法律规定的范围内，您可以申请查询、更正或删除个人信息，撤回同意，注销账户，或对信息处理提出异议和投诉。部分记录可能因财务、审计、安全或法定义务在必要期限内继续保存。

如需行使相关权利，请通过微信客服 `mahw649` 联系，并提供足以核验账户归属的信息。请勿通过公开渠道发送密码、完整 API Key 或其他敏感凭证。

## 九、未成年人

TogoAPI 不设置统一的年龄门槛。未具备完全民事行为能力的用户，应在监护人指导下使用服务；监护人应根据当地适用法律评估并承担相应责任。我们不会主动以未成年人为对象收集超出服务所必需的信息。

## 十、政策更新

我们可能根据法律、业务和技术变化更新本政策。重大变更将通过站内公告、登录提示或其他合理方式告知，并在需要时重新取得您的确认。
