# TogoAPI 使用政策

**生效日期：2026 年 8 月 1 日**

本政策适用于通过 TogoAPI 网站、API Key、接口及相关功能进行的全部活动，是《TogoAPI 服务条款》的组成部分。

## 一、基本原则

您只能在适用法律法规、上游服务条款及您拥有必要权限的范围内使用 TogoAPI。您应对请求内容、使用目的、模型输出的审查及后续使用承担责任。

## 二、禁止用途

不得使用本服务从事或协助从事以下活动：

1. 违反适用法律法规、监管要求、司法或行政命令；
2. 制作、传播或协助传播违法有害内容；
3. 欺诈、诈骗、钓鱼、冒充他人、操纵交易或误导公众；
4. 未经授权获取、披露、买卖或处理个人信息、商业秘密及其他受保护数据；
5. 生成、传播恶意代码，实施网络攻击、漏洞利用、凭证窃取、拒绝服务或绕过安全控制；
6. 侵犯著作权、商标权、专利权、肖像权、名誉权或其他合法权益；
7. 对个人进行违法歧视、跟踪、监控、画像或自动化高风险决策；
8. 制作或传播涉及未成年人的违法、有害或剥削性内容；
9. 在医疗、法律、金融、安全等高风险场景中，将未经专业人员核验的模型输出作为唯一决策依据；
10. 规避 TogoAPI 或上游提供商的地域限制、身份验证、访问控制、速率限制、计费规则、安全机制或内容政策；
11. 探测、攻击、干扰平台、其他用户或上游服务，或以异常并发、自动化流量影响服务稳定性；
12. 出售、出租、共享或滥用账户及 API Key，或以批量注册等方式规避限制。

## 三、API 与自动化使用

1. 您应设置合理的超时、重试、并发和速率控制，避免重复请求或重试风暴。
2. 不得在客户端代码、公开仓库、日志、截图或不受信任环境中暴露 API Key。
3. 应对面向最终用户的应用实施必要的身份验证、权限控制、内容审核和滥用防护。
4. 不得伪造来源、隐藏违法行为或干扰平台的安全审计及计费记录。

## 四、平台措施

为保护用户、平台和第三方，TogoAPI 可对异常或涉嫌违规的请求进行自动或人工研判，并可采取提醒、限流、阻断请求、暂停 Key、冻结账户、终止服务或依法保存并提供必要记录等措施。

平台采取措施不代表对所有内容进行事前审查，也不免除用户自身责任。对处理结果有异议的，可通过微信客服 `mahw649` 提交说明和必要证明。

## 五、政策更新

本政策可能根据法律法规、业务风险及上游政策变化进行更新。更新后继续使用服务，表示您接受更新后的政策；涉及重要权益的变更将通过合理方式提示。
