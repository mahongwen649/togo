# 账号套餐 Core 账号功能验收清单

Core 源码不得修改。Portal 仅增加套餐账号过滤、权限控制和安全代理。

## 验收规则

- `[x]` 已通过代码、自动化测试或真实页面检查。
- `[!]` 实现已具备，但当前环境缺少可用的 Core 测试数据或凭据，必须补做真实链路验收。
- `[ ]` 未完成，不得进入发布验收。
- 任何一项“完整用量窗口”或权限隔离失败，整体验收不通过。

## 数据与权限
- [x] 只返回当前用户有效套餐绑定的 Core Account ID。
- [x] 过期账号不出现在有效列表；修改 URL、Account ID 或参数不能越权。
- [x] 用量、刷新、查询、重置、调度、测试均由后端再次校验账号归属。
- [x] Core 管理员凭据不暴露到浏览器。

## 账号表格
- [x] 展示名称、状态、调度、用量窗口、最近使用、操作。
- [x] 展示正常、错误、限流、过载、暂停、到期、加载和错误状态。
- [x] 调度开关成功/失败行为正确；不显示编辑、删除、凭据、重授权、分组、代理和管理员入口。

## 用量窗口
- [x] 5h、7d 展示进度、百分比、到期/重置时间。
- [x] 每组展示请求数、Token、A 费用、U 费用、估算总费用。
- [x] 保留 7d Sonnet、7d Fable 及平台专属窗口（适用账号显示）。
- [x] 保留被动采样、查询、加载、错误、空数据、次数、重置和“+N 展开”。
- [x] OpenAI OAuth 的“次数”按钮调用 Core 对应 quota refresh 接口，展示可用次数、最早到期时间、全部到期明细展开、重置确认、重置结果和持久化失败提示。
- [x] 查询后视图、统计、重置时间和费用更新；Portal 不自行计算额度。
- [x] 移动端懒加载和批量请求不重复、不串账号。

## 操作与测试弹窗

- [x] 用户端不开放编辑功能，任何 URL/事件都不能触发编辑。

- [x] 具备 Core 通用配额限制的账号保留“重置配额”操作；不出现编辑、删除、凭据、代理、分组、重新授权和管理员专属入口。
